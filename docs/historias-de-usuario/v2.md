# Histórias de Usuário — v2 (revisada)

> Mudanças em relação à v1: adicionamos critérios de aceitação, separamos o agente em empresa/banco
> quando faz diferença e incluímos histórias que apareceram durante o desenvolvimento (US09 a US14).

### US01 — Cadastro de cliente
**Como** cliente, **quero** me cadastrar informando meus dados **para** poder usar o sistema.
- Dados obrigatórios: login, senha (mín. 6 caracteres), RG, CPF, nome e endereço.
- Profissão é opcional.
- Posso informar até **3** entidades empregadoras com seus rendimentos.
- Não pode existir outro cliente com o mesmo CPF nem outro usuário com o mesmo login.

### US02 — Login
**Como** usuário (cliente ou agente), **quero** entrar com login e senha **para** acessar as funções do sistema.
- Sem login nenhuma tela (fora login e cadastro) pode ser acessada.
- Login ou senha errados mostram mensagem de erro.
- Ao sair (logout) o token é invalidado.

### US03 — Introduzir pedido
**Como** cliente, **quero** criar um pedido de aluguel escolhendo o automóvel e o período **para** alugar um carro.
- A data de início não pode estar no passado e a data de fim deve ser depois da de início.
- O automóvel não pode estar aprovado ou contratado para outro pedido no mesmo período.
- O pedido é criado com status **PENDENTE**.

### US04 — Modificar pedido
**Como** cliente, **quero** modificar meu pedido **para** corrigir carro ou datas.
- Só é possível enquanto o pedido estiver **PENDENTE**.
- O agente também pode modificar pedidos **PENDENTES** ou **APROVADOS**.
- Ao modificar um pedido aprovado, ele volta para **PENDENTE** e precisa de nova avaliação.

### US05 — Consultar pedidos e status
**Como** cliente, **quero** ver meus pedidos e o status de cada um **para** acompanhar a análise.
- O cliente só vê os próprios pedidos; o agente vê todos.
- Deve aparecer o parecer do agente quando houver.
- Deve ser possível filtrar por status.

### US06 — Cancelar pedido
**Como** cliente, **quero** cancelar um pedido **para** desistir do aluguel.
- Só pedidos **PENDENTES** podem ser cancelados. O status muda para **CANCELADO**.

### US07 — Avaliar pedido (análise financeira)
**Como** agente, **quero** analisar financeiramente um pedido vendo os rendimentos do cliente **para** aprovar ou reprovar.
- O parecer é obrigatório.
- A aprovação é bloqueada se o automóvel já estiver reservado no período.
- O status muda para **APROVADO** ou **REPROVADO** e o agente avaliador fica registrado.

### US08 — Executar contrato
**Como** agente, **quero** gerar o contrato de um pedido aprovado **para** concretizar o aluguel.
- Só pedidos **APROVADOS**; o pedido passa a **CONTRATADO**.
- Informo de quem fica a propriedade do automóvel: cliente, empresa ou banco.

### US09 — Conceder crédito (novo)
**Como** banco, **quero** associar um contrato de crédito ao aluguel **para** financiar o cliente.
- Opcional ao gerar o contrato. Só agentes do tipo **BANCO** podem conceder crédito.
- Registra valor, número de parcelas e taxa de juros.

### US10 — Gerenciar meus dados (novo)
**Como** cliente, **quero** consultar, editar e excluir meu cadastro **para** manter meus dados atualizados.
- Se a senha ficar em branco na edição, a antiga é mantida.
- Não é possível excluir um cliente que já tem pedidos.

### US11 — Gerenciar automóveis (novo)
**Como** agente, **quero** cadastrar, editar e excluir automóveis (matrícula, ano, marca, modelo, placa) **para** que os clientes possam escolher.
- Placa e matrícula não podem repetir.
- O agente que cadastra fica como proprietário inicial.

### US12 — Consultar clientes (novo)
**Como** agente, **quero** ver a lista de clientes com seus rendimentos **para** apoiar a análise financeira.

### US13 — Consultar contratos (novo)
**Como** usuário, **quero** ver os contratos gerados **para** saber valores, propriedade e crédito associado.
- O cliente vê só os dele.

### US14 — Restringir acesso por perfil (novo)
**Como** sistema, **quero** bloquear funções de agente para clientes e vice-versa **para** garantir a segurança.
- Back-end responde 403 e o front esconde/redireciona as telas.
